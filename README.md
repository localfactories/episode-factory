# Episode Factory

Update packages for Episode Factory, a program that turns a written script and fifteen seconds of a
voice into a finished, narrated, long-form 4K film on your own graphics card. One click installs,
one click runs, nothing to pay per episode.

This repository holds only update packages. `version.json` names the newest version and is what
every installed copy checks once a day. The packages under `releases/` are encrypted; they open
only from inside a purchased copy, which carries the password, and a licence key is still needed
to install.
